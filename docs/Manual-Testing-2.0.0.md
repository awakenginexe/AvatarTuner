# AvatarTuner 2.0.0 manual test checklist

All items are **pending** until you perform them and supply results. No Unity or VRChat test has been run for 2.0.0, and no release has been published. Work in a backed-up test project and record the Unity version, target platform, SDK and package versions, avatar, settings, and outcome for every run.

## Install and compile

- [ ] In VCC create or copy a test project using Unity 2022.3.22f1. Install this checkout as a local package via Unity Package Manager's **Add package from disk**, selecting its `package.json`. Avoid installing a second copy via VCC or `.unitypackage`.
- [ ] Open the project yourself, wait for imports and compilation, and record all Console errors and warnings. Open **Tools → AvatarTuner**, select a scene avatar, analyze it and open the workspace.

## Content and settings

- [ ] Include color/sRGB and linear textures, HDR, normal maps, packed masks, MatCaps, ramps, transparent hair, detailed face and eyes, mixed/shared usage and an unknown or ambiguous case. Record categories, evidence, protections and corrections. Compare colors, mask channels, transparency edges and shader appearance before and after; HDR/normal/ambiguous candidates that cannot be validated should remain unchanged.
- [ ] Open Optimize Avatar, switch between Standard and Advanced, and edit settings. Confirm that no candidate import or compression occurs until Confirm & Optimize (or an explicit optional preview). One confirmation must evaluate and apply acceptable results without a separate Evaluate action. Cancel during evaluation must prevent generation/application; a no-change evaluation must not create output.
- [ ] In Advanced start with no checked textures, include only selected ones, enter different custom targets (including fractions and values above 16x), then Confirm & Optimize once. Unchecked/protected textures must stay unchanged. Check Global → Category → Custom precedence, reset, bulk edits and exclusion controls. Switch modes and close/reopen: Advanced tuning and selection must persist per avatar. Test a second avatar.
- [ ] Verify Advanced targets choose the closest acceptable SDK-memory estimate; inspect original/optimized/difference previews and actual achieved ratios. Test default and Best Quality encoding effort. Cancel evaluation and check temporary cleanup; repeat with a safe forced failure and verify rollback. Turn off Overwrite Generated and verify both modes request confirmation before replacing outputs.
- [ ] After optional preview, change a renderer material slot, shader/material contents, hierarchy, or protection component. Confirm & Optimize must evaluate the current inputs again. Changes during processing must invalidate the in-flight plan. Include duplicate and empty material slots and confirm slot indices remain correct.

## Preview, apply and compatibility

- [ ] Check actual generated imports, dimensions, formats, mip counts, color space and alpha. Compare selected source/candidate thumbnails and difference view at multiple zoom levels; switch selection and close/reopen. Exercise docked narrow and wide layouts, keyboard navigation and focus.
- [ ] Apply to a scene avatar, inspect material assignments and generated animation clip/controller copies, then test Undo and Restore. Test animated material swaps in relevant playable layers and verify behavior before/after restore. Check source texture, material, prefab, animation and controller files remain unchanged.
- [ ] Re-optimize after excluding a previously optimized texture while other textures still change. Verify old generated references are restored or replaced before old assets are removed, and unrelated manual assignments survive. In a backed-up test project, make the existing manifest read-only, attempt re-optimization, remove the read-only flag, and verify previous material/controller/clip references, generated bytes and recovery records survive the failed save. Check the Console for rollback errors; do not treat this as passed from the offline file tests.
- [ ] Test representative VRCFury, Modular Avatar, lilToon, NonToon, Avatar Optimizer and d4rkAvatarOptimizer setups. Verify protections, warnings, shader appearance and animation behavior. With NDMF installed, compare builds with the optional pass disabled and enabled; confirm source assets remain unchanged and record any conflicts.
- [ ] Test Windows target and Android target separately. For Android, activate the Android build target, choose Android in Global settings and confirm decoding support before testing ASTC 4x4, 6x6 and 8x8; check unsupported cases are safely retained. Inspect generated imports on each target.

## Memory and VRChat

- [ ] Record source and generated imported dimensions, formats and actual mip counts, including shared textures, skipped textures and unknown formats/shapes. Compare the SDK-compatible format/mip arithmetic and deduplication with the displayed MB totals; check the Current Avatar SDK readout against the Builder for the same avatar and platform.
- [ ] Build and inspect the same avatar in VRChat before and after each relevant mode. Record the actual texture-memory metric and visual behavior under the same conditions. Record download/bundle size separately: it is not GPU texture memory or generated disk size. Explain any platform or build-pipeline differences observed rather than treating an estimate as a VRChat measurement.

## Return evidence

For each item report pass/fail/blocked, actual numbers and units, settings, platform, steps and expected versus observed behavior. Provide exact Unity Console and Editor logs, AvatarTuner report/manifest where relevant, and screenshots of settings, preview, imported texture Inspector, VRChat metrics or visual differences when useful. Do not mark a check passed without its result.

Offline-only check: `dotnet run --project Tests/Standalone~/AvatarTuner.StandaloneTests.csproj`. This does not replace Unity or VRChat testing.

API references checked for implementation: Unity 2022.3 [platform importer settings](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/TextureImporterPlatformSettings.html), [texture formats](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/TextureImporterFormat.html), [pixel readback](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Texture2D.GetPixels32.html), and [Undo rollback](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Undo.RevertAllDownToGroup.html). Documentation checks do not establish runtime correctness.
